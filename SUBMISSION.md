# Submission preparation

**Repository:** https://github.com/Aditimybbby/qvacc

**Description:** Hush is a private voice-memo app that turns recordings and
imported audio into editable text on your own laptop. It uses QVAC 0.20.0
`loadModel` and `transcribe` with Whisper Tiny; no cloud AI API is used.

**Why:** Voice notes are useful when typing interrupts a thought. They should
be easy to search and keep without sending the recording to an AI service.
