# Submission steps

1. Install and run Clarity using the README.
2. Confirm `npm run smoke` completes with real QVAC output.
3. Run `npx playwright install chromium` and `npm run capture`.
4. Review `evidence/clarity-working.png` and `evidence/runtime.json`.
5. Merge the feature branch preserving its three commits, or ensure the
   submitted repository's default branch contains the working application.
6. Publish an X post with the screenshot, repo link, and **@qvac** tag.
7. Submit both the repository URL and your real X post URL.
